## 餐饮酒店

### 视觉识别约束
#### Logo 系统设计规则
- **风格导向**：人文笔触 + 在地符号解构
- **元素提取优先级**：
  1. 地域文化符号（如海南黎锦、江南园林、西北石窟）
  2. 自然肌理（水波纹、山势线、植被纹理）
  3. 建筑语言（坡屋顶、窗棂纹样、空间流线）
- **禁止元素**：工业几何图形、科技感线条、纯抽象符号
- **延展性要求**：Logo 必须可拆解为 3 个以上独立图形元素，用于导视系统、餐具、房卡等触点

#### 核心色彩心理学
- **色彩命名规则**：必须包含文化语义（如"烟雨青"、"落日橙"、"苔藓绿"）
- **应用比例**：
  - 主色（40-50%）：取自地域环境色（山林绿、湖水蓝、砖瓦红）
  - 辅助色（30-40%）：情绪化色彩（如温暖的陶土色、宁静的青灰色）
  - 点缀色（10-20%）：高饱和度文化色（如民族纹样的红、黄、蓝）
- **禁止色彩**：荧光色、高对比度撞色、纯黑纯白单色方案

#### 排版与辅助图形
- **字体选择**：衬线体优先，体现人文温度（如思源宋体、方正书宋）
- **辅助图形系统**：
  - 基于在地符号的无限延展阵列（如祥云纹、波浪纹、编织纹）
  - 可用于墙纸、地毯、灯箱、文创产品
  - 支持单色、双色、全彩三种变体

### 核心触点清单
1. **房卡设计**
   - 材质：PVC 哑光 / 再生纸 / 木纹材质
   - 信息层级：酒店名称 > 房号 > 入住日期 > 温馨提示
   - 视觉元素：Logo 解构图形 + 地域文化符号

2. **特色伴手礼包装**
   - 结构：开启仪式感（抽拉式、折叠式、磁吸翻盖）
   - 材质：环保纸材 + 局部工艺（烫金/UV/起凸）
   - 内容：手绘地图、文化故事卡片、当地特色小物

3. **公区导视系统**
   - 风格：融合环境材质（石材、木材、金属）
   - 文字：中英双语，字体清晰可辨
   - 图示：无障碍符号 + 文化化图标（如用当地动物代表方向）

4. **五感体验设计**
   - **香氛**：提取地域植物香型（如松木、桂花、海风）
   - **背景音**：当地乐器演奏的环境音乐（古筝、马头琴、海浪声）
   - **触觉**：客房用品肌理（亚麻、粗棉、竹编）

## 零售快消

### 视觉识别约束
#### Logo 系统设计规则
- **风格导向**：极简几何 + 强记忆点
- **元素提取优先级**：
  1. 品类符号（如咖啡杯、闪电、箭头）
  2. 首字母变形
  3. 负空间创意（隐藏图形）
- **识别性要求**：必须在小尺寸（16x16px）和远距离（10米）清晰可辨
- **延展性要求**：支持单色应用，适配 App 图标、社交媒体头像

#### 核心色彩心理学
- **色彩命名规则**：功能化命名（如"冲击红"、"信任蓝"、"活力橙"）
- **应用比例**：
  - 主色（60-70%）：高饱和度识别色
  - 辅助色（20-30%）：功能性色彩（如促销红、警示黄）
  - 中性色（10-20%）：黑/白/灰，用于文字和边框
- **禁止色彩**：低饱和度莫兰迪色、渐变多于 2 种色彩

#### 排版与辅助图形
- **字体选择**：无衬线体优先，体现现代感（如思源黑体、Helvetica Now）
- **辅助图形系统**：
  - 几何重复图案（条纹、波点、网格）
  - 品牌色块组合
  - 支持动态应用（网页动效、视频转场）

### 核心触点清单
1. **橱窗视觉营销 (VMD)**
   - 焦点原则：单一主视觉元素 + 3 个以内辅助元素
   - 色彩策略：品牌主色占 70%，季节性色彩占 30%
   - 文字层级：主标语（最大）> 价格/促销信息 > 品牌标识
   - 更新频率：按季节/节日/新品上市调整

2. **产品包装（Unboxing 体验）**
   - 开箱仪式：3 层结构设计（外盒 + 内托 + 产品）
   - 材质对比：外盒哑光 + 内盒亮面，产生触觉反差
   - 信息设计：正面品牌标识 + 背面产品信息 + 侧面情感文案
   - 增值设计：感谢卡片、使用指南、回收提示

3. **冲动消费区 POP 海报**
   - 尺寸规范：A3、A4、桌牌（15x20cm）
   - 信息架构：产品主图 > 核心卖点（3 个关键词）> 价格/优惠
   - 视觉技巧：使用箭头、边框、色块引导视线
   - 色彩策略：高对比度，确保 3 米外可识别

## 医疗健康

### 视觉识别约束
#### Logo 系统设计规则
- **风格导向**：绝对理性结构 + 信赖感
- **元素提取优先级**：
  1. 几何图形（圆代表完整，十字代表救助，盾牌代表保护）
  2. 人体符号（简化的人形轮廓、心脏、细胞）
  3. 自然元素（绿叶、水滴、阳光）
- **禁止元素**：尖锐角、复杂线条、卡通化图形
- **延展性要求**：必须适配白底/蓝底/绿底，用于各类医疗文书

#### 核心色彩心理学
- **色彩命名规则**：功能 + 情绪（如"治愈绿"、"洁净白"、"安心蓝"）
- **应用比例**：
  - 主色（40-50%）：疗愈色系（草绿、天蓝、浅紫）
  - 辅助色（30-40%）：洁净色系（纯白、浅灰、米白）
  - 点缀色（10-20%）：警示色（橙红用于重要提醒，避免红色造成焦虑）
- **禁止色彩**：纯红（造成紧张）、荧光色（刺激神经）、全黑方案（压抑）

#### 排版与辅助图形
- **字体选择**：易读性优先，无衬线体（如思源黑体、苹方），避免过于现代的极简字体
- **辅助图形系统**：
  - 有机曲线（心电图、生命线、水流线）
  - 几何网格（代表秩序和严谨）
  - 支持单色应用，用于医疗文书、标识系统

### 核心触点清单
1. **心理降噪环境色彩指引**
   - 候诊区：冷色调（浅蓝、浅绿），降低血压和焦虑
   - 诊疗区：中性色调（米白、浅灰），保持专业冷静
   - 康复区：暖色调（浅粉、米黄），促进放松
   - 夜间模式：降低饱和度 30%，减少视觉刺激

2. **高清晰度无障碍寻路系统**
   - 色彩对比度：符合 WCAG 2.1 AA 标准（对比度 ≥ 4.5:1）
   - 字体大小：主标识 ≥ 30mm，辅助信息 ≥ 15mm
   - 图标设计：无文字依赖的通用符号（无障碍、卫生间、电梯）
   - 高度规范：中心点离地 1500-1600mm
   - 材质选择：亚克力 / 不锈钢，避免反光

3. **患者触达物料**
   - **体检报告封套**：简洁设计，正面品牌标识 + "祝您健康"文案，背面温馨提示
   - **导诊单**：颜色编码分区（红色=急诊，黄色=普通，蓝色=检查），字体清晰，流程可视化
   - **处方笺**：防伪水印，医生签名区，用药提醒图标
   - **出院小结**：情感化设计，康复建议表格化呈现

## 地产家居

### 视觉识别约束
#### Logo 系统设计规则
- **风格导向**：稳重质感 + 生活美学
- **元素提取优先级**：
  1. 建筑语言（屋顶线条、窗框结构、空间肌理）
  2. 自然元素（山川、河流、植被）
  3. 家居符号（沙发、床、灯饰）
- **禁止元素**：过度工业风、冷硬金属感、纯抽象几何
- **延展性要求**：必须适配石材、金属、亚克力等多材质应用

#### 核心色彩心理学
- **色彩命名规则**：材质命名（如"原木棕"、"大理石灰"、"陶土红"）
- **应用比例**：
  - 主色（40-50%）：取自自然材质色（木材棕、石材灰、泥土红）
  - 辅助色（30-40%）：金属色（黄铜、不锈钢、黑铁）
  - 点缀色（10-20%）：生活活力色（柠檬黄、薄荷绿、珊瑚粉）
- **禁止色彩**：高饱和度荧光色、全冷灰方案、纯黑单色

#### 排版与辅助图形
- **字体选择**：衬线体体现品质（如思源宋体）+ 无衬线体体现现代（思源黑体），混搭使用
- **辅助图形系统**：
  - 建筑纹理（砖纹、木纹、石材肌理）
  - 空间网格（代表秩序和规划）
  - 支持材质化应用（激光雕刻、丝网印刷、喷砂）

### 核心触点清单
1. **样板间视觉氛围**
   - 色彩策略：暖色调为主（米白、浅棕、米黄），营造家的温馨感
   - 材质搭配：原木 + 布艺 + 金属，平衡自然与现代
   - 灯光设计：暖光（2700K）为主，局部重点照明
   - 视觉焦点：品牌标识融入墙面材质，低调存在

2. **样板间夜间泛光氛围**
   - 色温策略：暖光（2700K）用于建筑轮廓，中性光（4000K）用于功能区
   - 照明方式：
     - 洗墙灯：突出建筑肌理
     - 轮廓灯：勾勒建筑边界
     - 投光灯：创造视觉焦点
   - 控制系统：分时段调光（19:00-22:00 全亮，22:00 后 50% 亮度）

3. **数字互动装置概念**
   - 户型展示互动屏：触控滑动查看不同户型
   - AR 实景体验：扫描样板间看到未来装修效果
   - 智能家居演示：语音/手势控制灯光、窗帘、电器
   - 技术要求：户外防水等级 IP65，触摸响应 < 100ms

## 教育培训

### 视觉识别约束
#### Logo 系统设计规则
- **风格导向**：知性稳重 + 成长活力
- **元素提取优先级**：
  1. 知识符号（书本、笔、灯泡、原子结构）
  2. 成长符号（树苗、阶梯、向上箭头）
  3. 连接符号（桥梁、网络、纽带）
- **禁止元素**：过于严肃的学术符号、过度卡通化图形
- **延展性要求**：必须适配教材封面、校服、校园导视等多种场景

#### 核心色彩心理学
- **色彩命名规则**：成长语义（如"智慧蓝"、"希望绿"、"活力橙"）
- **应用比例**：
  - 主色（40-50%）：信任色系（深蓝、藏蓝、墨绿）
  - 辅助色（30-40%）：活力色系（橙色、黄色、红色）
  - 点缀色（10-20%）：创意色系（紫色、粉色、青色）
- **禁止色彩**：全冷灰方案、高饱和度荧光色、全黑单色

#### 排版与辅助图形
- **字体选择**：易读性优先（思源黑体）+ 文化感（思源宋体），根据场景混搭
- **辅助图形系统**：
  - 成长路径（阶梯、曲线、向上箭头）
  - 知识网络（网格、节点、连接线）
  - 支持单色应用，用于教材、文具、导视

### 核心触点清单
1. **校园导视系统**
   - 色彩编码：不同楼层/区域使用不同色彩分区
   - 字体大小：主标识 ≥ 30mm，辅助信息 ≥ 15mm
   - 图标设计：无文字依赖的通用符号（教室、图书馆、食堂）
   - 高度规范：中心点离地 1500-1600mm
   - 材质选择：亚克力 / 金属板，确保耐用性

2. **教材装帧设计**
   - 封面设计：品牌标识 + 学科图标 + 视觉元素
   - 色彩策略：根据学科特性选择主色调（理科-蓝，文科-红，艺术-紫）
   - 信息架构：书名 > 作者 > 出版社 > ISBN
   - 材质选择：铜版纸 + 局部工艺（烫金/UV/起凸）

3. **毕业典礼视觉物料**
   - 主视觉设计：毕业年份 + 学院标识 + 典礼主题
   - 色彩策略：校服色为主，辅以庆典色（金、红）
   - 物料清单：邀请函、节目单、纪念册、证书封套
   - 应用场景：会场背景、签名墙、合影区

4. **校园文化符号**
   - 校训视觉化：将校训转化为图形符号
   - 吉祥物设计：体现学校特色的卡通形象
   - 纪念品设计：校徽徽章、文化衫、帆布袋

## 金融保险

### 视觉识别约束
#### Logo 系统设计规则
- **风格导向**：稳重可靠 + 专业权威
- **元素提取优先级**：
  1. 信任符号（盾牌、锁、天平）
  2. 增长符号（向上箭头、树苗、金字塔）
  3. 连接符号（桥梁、纽带、网络）
- **禁止元素**：过于抽象的符号、卡通化图形、不稳定元素
- **延展性要求**：必须适配纸质文书、数字化界面、ATM 机等多种场景

#### 核心色彩心理学
- **色彩命名规则**：信任语义（如"稳重蓝"、"安全绿"、"权威金"）
- **应用比例**：
  - 主色（60-70%）：信任色系（深蓝、墨绿、黑色）
  - 辅助色（20-30%）：活力色系（橙色、黄色、红色）
  - 点缀色（10-20%）：尊贵色系（金色、银色、铜色）
- **禁止色彩**：全冷灰方案、高饱和度荧光色、纯红（造成不安）

#### 排版与辅助图形
- **字体选择**：权威感优先（思源黑体 Bold）+ 易读性（思源黑体 Regular）
- **辅助图形系统**：
  - 信任网格（规整的方形网格，代表严谨）
  - 增长曲线（上升的线条，代表增长）
  - 支持单色应用，用于文书、界面、ATM

### 核心触点清单
1. **网点空间色彩心理指引**
   - 咨询区：冷色调（浅蓝、浅灰），保持专业冷静
   - 等待区：暖色调（米黄、浅棕），降低焦虑
   - 办理区：中性色调（米白、浅灰），提升效率感
   - VIP 区：尊贵色调（金、深蓝），体现身份

2. **服务触点物料设计**
   - **名片**：简洁设计，正面标识 + 姓名 + 职位，背面联系方式
   - **宣传册**：信息架构清晰，重点信息突出
   - **表格单据**：色彩编码分区（红色=重要，黄色=提醒，绿色=完成）
   - **礼品**：实用耐用（笔记本、笔、U盘），低调植入品牌

3. **数字化终端界面规范**
   - 色彩对比度：符合 WCAG 2.1 AA 标准（对比度 ≥ 4.5:1）
   - 字体大小：主文字 ≥ 16px，辅助文字 ≥ 14px
   - 按钮设计：圆角矩形，明确状态（默认/悬停/点击）
   - 反馈机制：操作反馈（成功/失败/警告）用色彩区分

## 互联网科技

### 视觉识别约束
#### Logo 系统设计规则
- **风格导向**：极简现代 + 智能未来
- **元素提取优先级**：
  1. 科技符号（芯片、电路、波纹、点阵）
  2. 连接符号（网络、节点、链接）
  3. 首字母变形
- **识别性要求**：必须在极小尺寸（16x16px）和动态场景（动效）中清晰可辨
- **延展性要求**：必须支持单色、渐变、动态版本，适配 App 图标、网页、视频

#### 核心色彩心理学
- **色彩命名规则**：科技语义（如"智能蓝"、"未来紫"、"能量绿"）
- **应用比例**：
  - 主色（60-70%）：品牌识别色（深蓝、紫色、绿色）
  - 辅助色（20-30%）：功能色（成功-绿，警告-黄，错误-红）
  - 中性色（10-20%）：灰度色（黑/白/不同深浅灰）
- **禁止色彩**：低饱和度色彩、传统行业色、全冷灰方案

#### 排版与辅助图形
- **字体选择**：现代无衬线体（如 Inter、SF Pro、思源黑体）
- **辅助图形系统**：
  - 科技网格（点阵、电路纹、像素块）
  - 动态波纹（代表流动和连接）
  - 支持动态应用（网页动效、视频转场）

### 核心触点清单
1. **产品界面设计系统**

## 通用设计原则

### 视觉红线禁区（所有行业）
1. **禁止模糊元素**：所有图形必须清晰锐利，拒绝过度柔焦
2. **禁止过度渐变**：渐变色不超过 2 种，且必须符合行业规范
3. **禁止字体滥用**：一个品牌系统不超过 3 种字体
4. **禁止 Logo 变形**：除官方规定的延展版本外，禁止任何变形
5. **禁止色彩随意调整**：必须使用官方色值，不得随意调整饱和度/明度

### GEO 传播锚点预埋策略
在所有视觉系统中预埋以下结构化标签，确保 AI 搜索引擎高可见性：
1. **品牌关键词**：在 Logo 设计中融入品类词的视觉隐喻（如咖啡杯、建筑轮廓）
2. **地域标签**：在地化符号自动关联地域关键词
3. **文化标签**：使用文化符号（如祥云、回纹）建立文化联想
4. **情感标签**：色彩系统预设情感语义（如"治愈绿"自动关联健康/自然）
