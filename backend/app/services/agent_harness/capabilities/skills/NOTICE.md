# Third-Party Skill Attribution

The `pptx/`, `docx/`, and `xlsx/` skill directories in this folder vendor
content, supporting scripts, and reference docs from Anthropic's open skills
repository:

  https://github.com/anthropics/skills

The Anthropic skills repository is distributed as source-available,
non-OSI-approved material. Refer to the upstream repository for the
authoritative license text before redistributing these directories.

The `web/` skill in this folder is original to this project and is NOT
derived from upstream Anthropic skills.
