## 应用系统尺寸与比例规范模板

每个应用模块必须包含以下信息：

### 模板结构

| 物料名称 | 尺寸规格 | Logo比例 | Logo位置 | 安全区域 | 备注 |
|----------|----------|----------|----------|----------|------|
| | | | | | |

### 填写说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 物料名称 | 应用物料的具体名称 | 名片（横版） |
| 尺寸规格 | 实际物理尺寸（mm）或像素尺寸（px） | 90×54mm / 1920×1080px |
| Logo比例 | Logo占整体的比例范围 | 高度占10-15% / 宽度占20-30% |
| Logo位置 | Logo在物料上的标准位置 | 左上/居中/右下 |
| 安全区域 | Logo周围最小空白区域 | Logo宽度的50% |
| 备注 | 特殊说明或可调整范围 | 深色背景使用反白版 |

## 尺寸图与比例图标注规范

### 尺寸图必须包含

1. **整体尺寸标注**：长×宽（mm或px）
2. **关键元素位置**：标注各元素到边缘的距离
3. **安全区域线**：虚线标注Logo最小安全区域
4. **比例参考线**：黄金分割/三分法等辅助线

### Logo比例图必须包含

1. **Logo最小使用尺寸**：标注允许的最小Logo尺寸
2. **Logo最大使用尺寸**：标注允许的最大Logo尺寸
3. **比例对照表**：列出不同场景下的推荐尺寸
4. **错误示例**：标注比例失衡的示意

### 标注格式示例

```
┌─────────────────────────────────┐
│                                 │
│   [尺寸标注]                    │
│   宽度：90mm                    │
│   高度：54mm                    │
│                                 │
│   ┌─────────┐                   │
│   │  Logo   │ ← Logo比例：10-15%│
│   └─────────┘   位置：左上      │
│                                 │
│   ┌ - - - -┐ ← 安全区域：5mm   │
│   │ Logo   │                    │
│   └ - - - -┘                    │
│                                 │
└─────────────────────────────────┘
```
