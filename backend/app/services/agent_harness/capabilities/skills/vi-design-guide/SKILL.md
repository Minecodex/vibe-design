# VI视觉识别系统设计指南

## 任务目标
- 本Skill用于：指导品牌VI视觉识别系统的完整设计流程
- 能力包含：VI基础系统设计、应用系统设计、用户信息收集、设计确认机制、交付物管理
- 触发条件：用户表达"设计VI"、"做品牌视觉"、"升级品牌"、"需要VI手册"等意图

## 前置准备
- 确认用户是否提供品牌核心信息（品牌名称、定位、核心卖点、关键词/人格）
- 确认是全新品牌设计还是品牌升级/VI重塑
- 收集用户的审美偏好与对标参考（若无则由AI智能生成）
- 准备用户信息收集模板（见资源索引）

## 操作步骤

### 阶段一：用户信息收集与需求确认

#### 1.1 核心信息收集

| | 目标受众 | 主要用户群体画像 | [ ]已提供 [ ]待生成 |
| | 行业属性 | 科技/消费/金融/教育等 | [ ]已提供 [ ]待生成 |

**标注规则：**
- 必须项（品牌名称、定位、核心卖点、目标受众、行业属性）：若缺失则AI自动生成
- 可选项（人格描述、审美偏好）：若无则标注"待定"，AI可提供建议

#### 1.2 信息确认
将收集的信息整理后展示给用户确认，明确标注AI自动生成的部分。

**阶段一输出要求：**
- 在调用 `ask_user` 进行确认前，必须先用普通 assistant 正文输出一段可独立阅读的「品牌基础简报」。不要只说“我会补全简报”或把简报藏在交互卡片标题/描述里。
- 简报至少包含：品牌名称、项目类型、品牌定位、核心卖点、目标受众、行业属性、品牌关键词/人格、视觉风格假设、待确认事项。
- 对用户未提供但 AI 推断的内容，逐项标注“AI 假设”；对用户已明确提供的内容，标注“用户提供”；暂不能确定且会影响后续设计的内容，标注“待确认”。
- `ask_user` 只用于承接用户决策，例如“确认进入 Logo 线稿阶段 / 调整定位 / 调整视觉风格”。不要让 `ask_user` 的标题、问题或 description 替代简报正文。

**推荐展示格式：**

| 项目 | 内容 | 来源/状态 |
|------|------|-----------|
| 品牌名称 | 用户提供的品牌名 | 用户提供 |
| 项目类型 | 新品牌创建 / 品牌升级 / 品牌重塑 | AI 假设或用户提供 |
| 品牌定位 | 一句话定位 | AI 假设 / 待确认 |
| 核心卖点 | 2-3 条差异点 | AI 假设 / 待确认 |
| 目标受众 | 核心用户画像 | AI 假设 / 待确认 |
| 行业属性 | 所属行业与消费场景 | AI 假设 / 待确认 |
| 品牌关键词 | 3-5 个关键词 | AI 假设 / 待确认 |
| 视觉风格假设 | 初步视觉气质与禁忌 | AI 假设 / 待确认 |

完成上述可见简报后，再调用 `ask_user` 让用户确认是否进入阶段二。

### 阶段二：VI基础系统设计

#### 2.1 标志设计规范 (Logo Specifications)

**Logo设计分为三个子阶段，每阶段必须用户确认后才能进入下一阶段：**

---

##### 2.1.1 阶段A：线稿图设计

**设计内容：**
- Logo线稿图：纯线条勾勒的轮廓方案，展示造型、结构与比例
- Logo尺寸图：标注关键尺寸、比例关系、网格对齐

**输出形式：**
- 提供2-3个线稿方案供选择
- 每方案包含：正方形构图版、横向构图版、纵向构图版

**用户确认点：**
- [ ] 造型方向是否符合预期
- [ ] 结构比例是否协调
- [ ] 是否有修改意见

**确认通过后进入下一阶段。**

---

##### 2.1.2 阶段B：配色方案设计

**前置条件：** 线稿图已确认

**设计内容：**
- 主标准色（Brand Colors）：品牌核心基调色
- 辅助色/点缀色（Secondary Colors）：丰富视觉层次
- 功能色：成功/警告/错误等状态色

**效果图要求：**
配色方案必须结合已确认的线稿图进行效果展示：
- **配色方案效果图**：将配色应用到已确认的线稿图上，展示色彩填充效果
- 每个配色方案需提供：彩色版、单色版（用于深色背景）、反白版（用于浅色背景）
- 效果图需标注配色名称与色值

**输出形式：**
- 提供2-3个配色方案供选择
- 每个方案包含：
  - 配色效果图（结合线稿）
  - 配色色值卡（含RGB/HEX/CMYK/Pantone）
  - 配色说明（色彩情绪、适用场景）

**色值规范：**
| 类型 | 使用场景 | 色值格式 |
|------|----------|----------|
| RGB/HEX | 数字化屏幕 | #XXXXXX |
| CMYK | 印刷媒介 | C:0 M:0 Y:0 K:0 |
| Pantone | 精准配色 | PMS XXXX |

**配色策略参考：**
| 品牌类型 | 配色建议 |
|----------|----------|
| 科技品牌 | 高饱和度冷色（蓝、青）、极简黑白灰 |
| 消费品品牌 | 温暖色调（橙、黄）、活泼撞色 |
| 高端品牌 | 低饱和度、克制的用色 |

**用户确认点：**
- [ ] 配色方案效果图是否符合预期
- [ ] 主标准色是否满意
- [ ] 辅助色搭配是否协调
- [ ] 是否有特定颜色需求或禁忌

**确认通过后进入下一阶段。**

---

##### 2.1.3 阶段C：标志定稿

**前置条件：** 线稿图 + 配色方案均已确认

**设计内容：**
- 标志标准稿：Logo的图形、文字及组合的最终形态
- Logo尺寸图：最终版的精确尺寸标注
- 网格制图法：利用几何比例与数学网格精确定义Logo结构
- 空间安全隔离带：Logo周围必须留出的空白区域
- 标志最小使用尺寸：最小像素或毫米数限制
- 标志错误示范：严禁行为清单（随意拉伸、描边、更换颜色、倾斜等）

**输出形式：**
- 标志标准稿（彩色版）
- 标志标准稿（反白版/单色版）
- 标志尺寸图（含安全隔离带标注）
- 标志网格制图

**用户确认点：**
- [ ] 最终标志效果是否满意
- [ ] 尺寸图信息是否清晰
- [ ] 是否有其他调整需求

**全部确认后完成标志设计模块。**

#### 2.2 扩展色彩系统 (Extended Color Palette)

**前置条件：** 标志配色方案已确认

**设计内容：**
在Logo配色基础上，扩展为完整的品牌色彩系统：
- 辅助色/点缀色（Secondary Colors）：丰富视觉层次，用于UI界面中高亮态
- 功能色：成功/警告/错误/信息等状态色
- 中性色：黑白灰体系，用于正文、背景、分割线

**色值规范：**
| 类型 | 使用场景 | 色值格式 |
|------|----------|----------|
| RGB/HEX | 数字化屏幕 | #XXXXXX |
| CMYK | 印刷媒介 | C:0 M:0 Y:0 K:0 |
| Pantone | 精准配色 | PMS XXXX |

**用户确认点：**
- [ ] 扩展色彩是否与主色协调
- [ ] 功能色区分是否清晰
- [ ] 是否有其他色彩需求

#### 2.3 标准字体系统 (Typography)
**输出内容：**
- 品牌专属印刷字体（中文/英文）
- 企业日常办公字体
- UI/数字端字阶规范

**字阶规范示例：**
| 层级 | 字号 | 字重 | 使用场景 |
|------|------|------|----------|
| H1 | 48-72px | Bold | 主标题 |
| H2 | 32-48px | Semibold | 副标题 |
| Body | 16-18px | Regular | 正文 |
| Caption | 12-14px | Regular | 注释 |

#### 2.4 辅助图形与延展纹样 (Supporting Elements)
**输出内容：**
- 辅助图形（Super Graphic）：从Logo提取的核心元素
- 质感与视觉风格定义：
  - Glassmorphism（毛玻璃透光）
  - 微渐变
  - 极致扁平留白
  - 其他特殊风格

**用户确认内容：** 确认设计规范参数，不确认实际图片

### 阶段四：设计确认机制

每个阶段完成后必须执行：

1. **阶段性成果展示**：以结构化方式呈现设计内容；若后续需要用户确认，先展示完整成果，再发确认交互
2. **用户确认**：明确询问"是否满意？有无修改意见？"；确认交互只承载决策，不承载阶段成果正文
3. **修改迭代**：根据用户反馈进行调整
4. **进入下一阶段**：仅在当前阶段确认后才执行

## 使用示例

### 示例1：全新品牌VI设计
- **场景/输入**：用户表示"我要创建一个名为XX的科技公司，需要完整的VI设计"
- **预期产出**：完整的VI基础系统 + 主要应用系统设计 + 交付物包
- **关键要点**：
  1. 先收集品牌核心信息（可引导式提问）
  2. 无审美偏好时智能生成3套方向供选择
  3. 每个阶段需用户确认

### 示例2：品牌视觉升级
- **场景/输入**：用户表示"我们公司要升级品牌视觉，现有VI是..."
- **预期产出**：新旧对比分析 + 升级方案 + 平滑过渡策略
- **关键要点**：
  1. 必须收集现有VI材料
  2. 分析现有问题与升级必要性
  3. 保持品牌资产延续性

### 示例3：VI设计咨询
- **场景/输入**：用户表示"我想了解VI设计都包含什么"
- **预期产出**：VI设计知识科普 + 本Skill能提供的服务说明
- **关键要点**：以问答形式解释VI设计要点
