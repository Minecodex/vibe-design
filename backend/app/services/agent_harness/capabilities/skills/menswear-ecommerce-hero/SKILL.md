# 男装电商图

按这个顺序推进：实拍图 -> 衣服细节锁定 -> 白底基准图 -> 白底图基准过审 -> 调用无参 `prepare_ecommerce_generation` 弹出选项卡片 -> 用户确认后由系统生成下一轮用户消息上下文 -> 模型根据上下文调用通用 `generate_image` -> QA 分析说明 -> 用户自行决策后续流程。

所有阶段都把商品真实一致性放在第一位。不要为了画面好看而脑补、替换、删减、重画商品细节；不要生成参考图中不存在的品牌、文字、吊牌、图案、配饰或装饰。

## 阶段一：实拍图到衣服细节锁定

用户上传男装实拍商品图后，对每张图片分别调用 `analyze_image` 做单图分析，再综合所有图片锁定“同一件主商品”的真实服装细节，输出可用于后续 AI 生图的《衣服细节锁定卡》。只分析真实可见的信息，不要想象、不要美化、不要替商品补设计。

分析时综合所有图片，不要只看其中一张。如果图片里出现模特、裤子、鞋、内搭、衣架、背景、道具，把它们视为非主商品，不要写入主商品细节。如果有多个商品或多件衣服混在一起，先判断主商品；无法判断时明确提示“主商品不确定”，并让用户补充说明。

对看不清的 logo、文字、印花、刺绣、洗标、吊牌，不要生成可读内容，只标记为“不确定 / 不可读 / 保持模糊相似”。不要输出营销文案，不要写卖点夸张词，不要写平台承诺。

《衣服细节锁定卡》按以下内容执行：

1. 主商品判断：判断主商品类目，可从 T 恤、衬衫、Polo、卫衣、夹克、西装、外套、大衣、针织衫、牛仔裤、休闲裤、短裤、套装等中选择；明确是否为单一主商品；说明模特、内搭、裤子、鞋、衣架、背景、道具等是否干扰识别；给出图片完整度评级 A / B / C。
2. 整体版型与轮廓：判断版型是修身、合体、常规、宽松、oversize、短款、长款、直筒、锥形、阔腿或不确定；判断肩部是正肩、落肩、插肩、垫肩或不确定；描述衣长或裤长；描述衣身、裤型、下摆和垂坠状态，不要美化。
3. 结构细节：逐项判断领型、门襟/开合方式、纽扣数量与位置、拉链位置与样式、口袋数量/位置/形状、袖长、袖口结构、下摆结构、后背结构、裤腰/腰头结构、裤袢、裤脚、明线、分割线、褶裥、拼接和其他特殊结构。能看清就写清楚，看不清就写“不确定”。
4. 颜色与图案：记录主色、辅助色/拼色；判断颜色是否受光线影响，并说明可能偏黄、偏蓝、过曝、阴影偏暗等；判断图案类型，如纯色、条纹、格纹、印花、刺绣、贴章、水洗、做旧或其他；记录图案位置；判断 logo/文字/刺绣是清楚可读、可见但不可读、不确定还是无。若不清楚，必须写明“后续生图不可生成可读新文字，只能保持模糊相似或按原图形态弱化”。
5. 面料与质感：判断面料类型，如棉感、牛仔、针织、羊毛感、尼龙感、皮革感、西装面料、灯芯绒、其他或不确定；判断厚薄；判断表面质感是哑光、微光泽、明显反光、粗纹理、细纹理、罗纹、水洗、做旧或不确定；判断垂坠感和褶皱状态。
6. 必须保持不变的商品事实：明确后续所有生图中类目、主色、版型、领型、袖型/袖口、口袋、纽扣/拉链、下摆/裤脚、面料纹理、logo/图案/刺绣和其他不可改变项。
7. 不确定信息与风险：列出看不清的区域、可能被遮挡的结构、可能偏色的图片、不可读文字/logo、缺失角度；判断是否需要补拍；给出建议补拍内容，如正面全身、背面、领口、袖口、口袋、面料、logo、吊牌等。
8. 白底基准图生成建议：给出推荐视角，如正面、背面、3/4 角度或其他；推荐画幅为 1:1；背景为纯白或接近纯白；展示方式为平整悬挂、自然立体、无模特、无道具；用一句话总结生成时必须强调的商品一致性要求；用一句话总结生成时必须避免的最大风险。
9. 最终衣服细节锁定卡：压缩成一段可直接复制到后续生图提示词里的【商品锁定描述】，格式为“这是一件男装[类目]，主色为[颜色]，[版型/廓形]，[领型/门襟/袖口/下摆/口袋等关键结构]，[面料与质感]。必须保持参考图中的颜色、版型、领型、袖型、口袋、纽扣/拉链、下摆、面料纹理、logo/图案/刺绣位置与形态一致。不得添加参考图中不存在的品牌、文字、吊牌、图案、配饰或装饰。看不清的文字/logo/图案不得生成可读新内容，只能保持模糊相似。若某些结构在参考图中不可见，标记为不确定，不得自行编造。”

完整输出《衣服细节锁定卡》后停住，等待用户用普通消息确认或修改；不要用交互卡片承载该确认。用户确认《衣服细节锁定卡》前，不要进入白底基准图生成。用户修改锁定卡后，以用户确认后的版本作为后续所有生图的最终商品事实。

## 阶段二：白底基准图生成

白底基准图 / 白底基准组只能在《衣服细节锁定卡》已确认后生成。调用通用 `generate_image` 生成白底基准图。以主商品实拍图和商品细节锁定卡为唯一商品依据；凡锁定卡中仍有不确定项，先确认后再生成，不得脑补、替换、删减、重画商品细节。

白底基准组的目标是锁定同一件商品的全部真实细节，供后续平铺图、挂拍图、穿搭图、风格图继续调用。输出一组独立白底图，建议至少 6 张，优先 8 张；不拼图、不合成；纯白无缝背景；单品居中；高清真实；只允许轻微自然阴影。

白底基准组必须完整覆盖主商品的真实结构与细节，包括但不限于正面全貌、背面全貌、左/右侧或 45 度、闭合状态、敞开状态、关键结构和局部细节特写。单张图无法同时展示的内容，必须由同组其他图片补齐，不能省略。

可开合类商品必须至少包含：

1. 一张闭合展示，完整呈现版型和正面结构。
2. 一张敞开展示，清楚呈现门襟、内侧和开合逻辑。
3. 一张重点细节特写，如领口、门襟、口袋、袖口、下摆、后背拼接、标签等。
4. 如果结构复杂，再补充侧面或背面细节图。

白底基准图中的结构逻辑必须严格正确。有纽扣的，只能出现在纽扣侧；扣眼侧只能出现扣眼、缝线或门襟边，不得凭空生成纽扣。有拉链的，必须清楚显示拉链头、齿牙、闭合状态和开合状态，不得改结构。有口袋、翻领、袖口开衩、育克、拼接线、下摆等，必须按锁定卡真实还原。允许自然褶皱和轻微垂感，但不能改变廓形、长度和结构。

如果主商品为衬衫、外套、夹克、开衫等可开合类，可使用基础白 T 或浅色中性内搭辅助展示，但内搭只能辅助说明版型与门襟，不得抢主体，不得改变商品真实结构。

标签、织标、洗标和尺码标必须按真实位置处理。先识别其在锁定卡和实拍图中的真实位置，再判断当前白底视角下应完整可见、部分可见还是被翻折或遮挡。如果在当前摆位中自然被门襟、翻折、内侧层或下摆遮住，就按真实遮挡处理；如果应当可见，就自然展示。不得移动、复制、放大、居中、强化、改字、虚构标签，也不得把标签做成装饰焦点。

像位于下摆、门襟内侧、扣眼翻折区域的织标，必须严格按真实遮挡关系决定展示程度。不得为了“看起来完整”而强行露出本应遮住的部分，也不得把本应可见的部分故意隐藏。

白底风格必须纯净克制：纯净白底、无道具、无人物、无场景、无文字、无水印、无边框、无促销信息、无品牌虚构元素。保持商品颜色、面料纹理、厚薄感、光泽、做工、线迹、版型与锁定卡完全一致。边缘干净，抠图自然，无毛边、无溢色、无 AI 感、无塑料感。画面重点是商品真实还原，不是氛围效果图。

白底基准图必须避免：错误的纽扣侧与扣眼侧、纽扣复制到错误一侧、纽扣缺失、门襟错位、拉链结构错误、口袋数量错误、左右结构镜像翻转、领型改变、袖型改变、廓形改变、长度改变、面料纹理改变、颜色偏移、标签位置错误、标签居中、标签放大、标签乱码、虚假文字、虚构 Logo、虚构织标、虚构吊牌、人物、模特、手、道具、背景装饰、场景化陈设、拼图、九宫格、边框、水印、价格牌、促销字、二维码、过曝、死黑、低清、模糊、毛边、抠图溢色、AI 塑料感、过度磨皮、结构变形、衣服穿模和细节丢失。

白底基准组完成后，不要自动继续生成商品图。等待用户确认白底图基准是否过审；如果用户提出微调意见，先按意见调整白底基准图；如果用户确认过审并要求继续，进入选项卡片阶段。

## 阶段三：商品图生成配置确认

白底图基准过审后，如果用户要生成电商商品图，调用无参 `prepare_ecommerce_generation`。该工具没有参数，只用于通知前端渲染“商品图生成配置卡”。本阶段只负责让用户选择并确认生成配置，不直接生成图片，不起草图片生成 prompt，不调用 `generate_image`。

商品图生成配置卡固定包含：

1. 参考图库中的图片分类下拉选择。
2. 图片风格下拉选择。
3. 是否开启背景图。
4. 是否开启人物参考图。
5. 是否开启其他商品主图参考图。
6. 生成商品图数量。

当背景图、人物参考图、其他商品主图参考图任一开关开启时，卡片中展示对应图片上传 UI。三类参考图的总数量限制必须与当前所选图片模型的参考图数量上限一致。卡片下方只有提交和取消两个按钮。

用户取消后，停止本次商品图生成。用户点击提交后，系统会根据用户确认的信息整理出下一阶段需要使用的商品图生成上下文，并把该上下文放入后续用户消息中。skill 不描述上下文拼接细节，也不把“商品图生成”目录中的提示词硬编码进 skill。

## 阶段四：根据确认上下文生成商品图

阶段四根据阶段三确认后形成的用户消息内容进行图片生成。该用户消息中已经包含本次商品图生成所需的商品锁定信息、白底基准信息、分类/风格选择、可选参考图信息、数量和用户需求。基于这条上下文自行组织通用 `generate_image` 的参数；图片生成发生在本阶段，而不是阶段三。

生成男装高转化电商商品图时，商品细节锁定卡为最终真值。白底基准组用于校验真实结构、比例、部件位置与自然遮挡关系，但不锁死后续摆位。参考图只学习布局、搭配、光影、色调与审美，不得改变主商品。

商品图中，主商品必须始终最大、最清晰、最完整，搭配仅辅助转化，不得喧宾夺主。可以根据用户消息生成对应类型的商品图，但任何类型都不能改变主商品的类目、颜色、版型、领型、袖型、口袋、纽扣/拉链、下摆/裤脚、面料纹理和 logo/图案/刺绣位置与形态。

标签和织标在商品图中仍需先判断真实位置，再判断当前摆位是否自然外露。自然外露则低调显示；自然遮挡则隐藏或部分隐藏；不得移动、复制、居中、放大或改字。

人物参考图只用于身材比例、镜头感和气质；背景参考图只用于场景结构、透视、光线、色调、景深、材质、道具位置与整体氛围；其他商品主图参考图只用于主图风格、构图、背景、人物姿态、镜头角度、光影与氛围。所有参考图都不得替代或改变当前主商品。

## 阶段五：生成后 QA 分析与用户自行决策

商品图生成后，检查是否符合商品锁定卡、白底基准组和用户配置。重点检查主商品是否最大、最清晰、最完整；结构、比例、部件位置、颜色、面料、标签/织标遮挡关系是否可信；是否出现虚构文字、虚构 Logo、错误结构、喧宾夺主的搭配或参考图商品替换主商品。

QA 只做分析和说明，不替用户决定下一步。说明每张生成图是否符合商品锁定卡、白底基准组和选项配置；如果不符合，指出具体问题和可调整方向；如果符合，说明它适合的使用场景。

QA 说明完成后等待用户自行决策后续流程。用户可以选择微调某一张图、重新弹出选项卡片换方向生成、回到白底基准图调整、继续生成其他商品图，或结束流程。用户对某一张商品图的后续微调为自由微调，不再展示商品图生成配置卡；但商品本体仍必须遵守已确认的商品细节锁定卡。

## 全局禁止事项

- 禁止跳过实拍图分析直接生成白底基准图。
- 禁止用户未确认《衣服细节锁定卡》就生成白底基准图。
- 禁止锁定卡中仍有不确定项时直接脑补生成。
- 禁止把模特、裤子、鞋、内搭、衣架、背景、道具写入主商品细节。
- 禁止把不同商品混成同一件商品。
- 禁止在看不清 logo、文字、印花、刺绣、洗标、吊牌时生成可读新内容。
- 禁止改变商品类目、主色、版型、领型、袖型/袖口、口袋、纽扣/拉链、下摆/裤脚、面料纹理、logo/图案/刺绣位置与形态。
- 禁止把参考图库图片、人物参考图、背景参考图或其他商品主图中的服装替换成当前主商品。
- 禁止把“商品图生成”目录中的提示词硬编码进 skill。
- 禁止商品图生成完成后的自由微调再次弹商品图生成配置卡。
